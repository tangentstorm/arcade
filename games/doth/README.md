# Doth

Silverware **Doth-A** (Turbo Pascal, 1993–1996) — Kroz-like adventure.

- `direct/game.tscn` — **80×25 CP437 TermGrid** (IBM VGA 8×16), DOSBox DOTH-A look.
  Visual reference: `source/doth-reference-dosbox.png`.
- `enhanced/game.tscn` — 1280×720 torchlit shell (still uses `direct/doth_tiles.gd` atlas).

Esc → Pause / Back to Arcade.
