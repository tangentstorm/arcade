# chesscoach

Status: **Direct playable**, Enhanced planned. Source: [tangentstorm/gd-chesscoach](https://github.com/tangentstorm/gd-chesscoach) (Godot 4.3). See [PORT.md](PORT.md).

Tiny FEN chessboard with piece trays. Reset loads the starting position; Replay plays the recorded game animation. Esc opens the arcade pause.

- **Direct:** playable FEN board + trays + recorded replay.
- **Enhanced:** planned (Stockfish / Go chesscoach not in this tile).
