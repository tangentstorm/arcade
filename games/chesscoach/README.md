# chesscoach

Status: **Direct playable**, **Enhanced playable**. Source: [tangentstorm/gd-chesscoach](https://github.com/tangentstorm/gd-chesscoach) (Godot 4.3). See [PORT.md](PORT.md).

Tiny FEN chessboard with piece trays. Reset loads the starting position; Replay plays the recorded game animation. Esc opens the arcade pause. No Stockfish.

- **Direct:** playable FEN board + trays + recorded replay.
- **Enhanced:** walnut board chrome, move-list HUD and replay juice over the same Direct scene (instanced, not copied).
