# toroidal_zombie_herder

From [gamemaker-stuff](https://github.com/tangentstorm/gamemaker-stuff) (GameMaker: Studio 1.x, 2017).
Herd zombies around a wrap-around maze onto traps while you collect coins.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** playable. `enhanced/game.tscn` is a visual/UI makeover over the same Direct rules (preloaded, not copied): crypt-stone maze, lantern-lit hero, shambling zombies with chase arrows, glowing wrap doors + wrap-around ghosts, coin / trap / caught juice, torus minimap + danger meter HUD, title card, Back to Arcade. No Alchementrix IP.
