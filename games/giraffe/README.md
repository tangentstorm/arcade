# Giraffe

From [tangentstorm/pico-games](https://github.com/tangentstorm/pico-games) (`giraffe.p8`), a tiny Pico-8
platformer by Michal J Wallace (giraffe sprite credited in-repo to Savleen).

Walk and jump on map tiles. Fall below the screen and you reset.

- **Direct:** playable. Faithful GDScript port of the cart; see [PORT.md](PORT.md).
- **Enhanced:** playable. Savanna-dusk presentation makeover (5× field, smooth hero, squash/stretch,
  dust, ledge tracker, side HUD) on the same Direct logic; see [PORT.md](PORT.md). Esc → PauseOverlay;
  letterbox; Back to Arcade. No Alchementrix IP.

Controls: arrows / A,D walk · Space / Z / X jump · Esc pause / Back to Arcade.
