# canyon_run

Status: **Direct + Enhanced playable**.

A River Raid–style vertical canyon shooter: fly up a scrolling canyon, steer
between the walls, shoot the red drifters, score distance.
See [PORT.md](PORT.md) for provenance, scope, and what is deferred.

- `direct/game.tscn` — playable MVP (240×320 portrait stage at 2×, letterboxed).
- `enhanced/game.tscn` — visual/UI makeover over the same Direct `canyon_logic.gd`
  (layered canyon chrome, clearer HUD, craft/bullet/kill/crash juice). Claude Design
  exact parity deferred (no reference screenshots). No Alchementrix IP.

Controls: ←/→ or A/D steer · ↑/↓ or W/S throttle · Space/Z fire (also starts / restarts) ·
Esc pause → Back to Arcade. There is also an on-screen "Back to Arcade" button.
