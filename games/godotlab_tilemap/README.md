# godotlab_tilemap

Status: **Direct + Enhanced playable**. Source: godotlab/tilemap (Godot 3). See [PORT.md](PORT.md).

The original Kenney "Platformer Deluxe" tilemap test level, with the pack's p1 alien added so you can walk it.
Walk with ←/→ or A/D, and jump with Space, ↑, or W. If you fall off, you respawn. Esc opens the arcade pause.

- **Enhanced:** playable. The same Direct level at ¾ in a 1280×720 letterbox stage: a sky with parallax hills, landing dust, jump puffs and an afterimage trail, a ground shadow, respawn juice, a minimap and run stats. **G** shows the 72-px tile grid and the original's 170 blank cells, and **R** reloads the level.
