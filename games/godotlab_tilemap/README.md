# godotlab_tilemap

Status: **Direct playable**, Enhanced planned. Source: godotlab/tilemap (Godot 3). See [PORT.md](PORT.md).

The original Kenney "Platformer Deluxe" tilemap test level, with the pack's p1 alien added so you can walk it.
Walk with ←/→ or A/D, and jump with Space, ↑, or W. If you fall off, you respawn. Esc opens the arcade pause.
