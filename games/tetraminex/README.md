# Tetraminex

Episode 0 ("Training Day") — Godot 4 ports of the AS3/Flixel demo.

- `direct/` — playable GDScript rewrite (NES-era chat chrome, salvaged art, grid move/grab/paint/cages)
- `enhanced/` — polished makeover: readable dialog card, procedural floor/paint/cage/block art, same rooms/logic as Direct
- `source/` — salvaged level CSVs, DAME `Level_RoomN.as`, and PNGs (`.gdignore`d)
- See `PORT.md` for provenance and gaps.
