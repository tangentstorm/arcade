# Cardinal Rule

Ludum Dare 25 (Nov 2012) start on a Joust × Defender mashup: a cardinal fending off vampire
bats over a wrapping landscape. Only the first sprite test was ever built.

See [PORT.md](PORT.md) and arcade issue #116.

- **Direct:** Godot 4 port of what exists: the flixel title text, then `spritetest.pas` —
  the cardinal on a blue stage, arrow keys add flap/steer impulses, gravity pulls it down.
  Click (or Enter/Space) on the title to play.
- **Enhanced:** planned.
