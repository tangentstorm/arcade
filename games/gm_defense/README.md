# gm_defense

From [gamemaker-stuff](https://github.com/tangentstorm/gamemaker-stuff) `gm2-defense/` (GameMaker Studio 2, 2017).
The start of a Defender clone: a ship that flies left and right past a squid. It's a toy, not a full game.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** playable. Presentation makeover on the same Direct rules: a deep-space room with
  parallax stars and a horizon grid, ship glow / exhaust / banking turns, a glowing squid, an
  off-room locator + radar, and side HUD panels. Esc → PauseOverlay; letterbox; Back to Arcade.
