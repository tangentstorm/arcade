# silly_game

Status: **Direct + Enhanced playable**. Source: [tangentstorm/silly-game](https://github.com/tangentstorm/silly-game) (archived Godot 3). See [PORT.md](PORT.md).

Walk the little aardvark (Michal called it the little elephant) with WASD, aim with the mouse, and click to shoot. Esc opens the arcade pause.

- **Direct:** playable walk + shoot loop on the original beach/water tilemap.
- **Enhanced:** `enhanced/game.tscn` — presentation makeover over the same Direct scene (instanced, not copied): animated ocean, shadows, bullet trails, muzzle flash, hit/BONK juice, minimap + stats HUD, title card, Back to Arcade. No Alchementrix IP.
