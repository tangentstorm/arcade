# silly_game

Status: **Direct playable**, Enhanced planned. Source: [tangentstorm/silly-game](https://github.com/tangentstorm/silly-game) (archived Godot 3). See [PORT.md](PORT.md).

Walk the little aardvark (Michal called it the little elephant) with WASD, aim with the mouse, and click to shoot. Esc opens the arcade pause.

- **Direct:** playable walk + shoot loop on the original beach/water tilemap.
- **Enhanced:** planned.
