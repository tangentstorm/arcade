# godotlab_game00

Status: **Direct + Enhanced playable**. Source: godotlab/game00 (Godot 3). See [PORT.md](PORT.md).

Use the arrow keys to push the Godot icon around. It coasts to a stop on friction and wraps at
the edges. Enhanced adds letterbox chrome, a motion trail, speed glow, wrap pops and telemetry
over the same Direct `icon.gd`. Esc opens the arcade pause.
