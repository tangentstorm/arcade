# brickslayer

Status: **direct playable**, enhanced planned.

Brickslayer is a Breakout-style game by Michal J Wallace, from javascriptgamer.com (2007). It was built step by step in an 11-lesson "trail".
- `direct/` is a GDScript port of the recovered lesson code, using the sprites mirrored from the live site.
- `trail/` is a CodeTrail-style lesson viewer. Press **T** in the game to step through the lessons and play the game as it stood at each one.
- See [PORT.md](PORT.md) and [source/ASSETS.md](source/ASSETS.md).
