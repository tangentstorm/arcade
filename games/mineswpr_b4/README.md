# Mineswpr (b4)

Arcade gallery host for the **b4** TermGrid mineswpr cart from
[b4-gd](https://github.com/tangentstorm/b4-gd) (arcade issue #45 Phase 4).

- **Gallery:** Original mode → **Mineswpr (b4)**
- **Direct:** vendored minimal b4 VM + `mineswpr-logic.b4` / `mineswpr-play.b4`
- Reuses `games/mineswpr/direct/term_grid.gd` and its Noto Sans Mono font
- Esc → PauseOverlay; typed `q` → Back to Arcade

See `PORT.md` and `games/mineswpr/PORT.md` (b4 path section).
