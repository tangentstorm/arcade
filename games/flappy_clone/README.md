# flappy_clone

Status: **Direct playable**, **Enhanced playable**.

Source: https://github.com/tangentstorm/unitylabs (`flappyclone/`, Unity 5, 2015).
See [PORT.md](PORT.md) for the source commit, fidelity notes and deviations.

- `direct/game.tscn` — faithful port (space / click / tap to flap).
- `enhanced/game.tscn` — modern makeover: procedural art, steady flaps, random fair gaps,
  score pop, soft crash landing and quick restart. Same gravity and scroll as Direct.
