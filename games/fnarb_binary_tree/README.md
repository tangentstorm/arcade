# fnarb_binary_tree

From [fnarbmlyx](https://github.com/tangentstorm/fnarbmlyx) `demos/binary_tree/` (Godot 4.1, 2023), tangentstorm's Godot scratch repo for
graph and algorithm-animation experiments. A visual sketch, not a game.

- **Direct:** playable. The original scene in a 1920×1080 stage; see [PORT.md](PORT.md).
- **Enhanced:** playable. 1280×720 letterbox chrome, grow-in reveal, traversal-wave halos and a hover inspector over the same Direct `binary_tree.tscn` (shared `binary_tree.gd`).
