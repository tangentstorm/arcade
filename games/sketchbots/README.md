# sketchbots

From [GameSketchLib](https://github.com/tangentstorm/GameSketchLib) course week 1 (Processing, ~2011).
A tiny "hello world" input demo by Michal J Wallace: move an orange bot in eight directions
next to a static blue bot. No goal or scoring.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** planned.
