# sketchbots

From [GameSketchLib](https://github.com/tangentstorm/GameSketchLib) course week 1 (Processing, ~2011).
A tiny "hello world" input demo by Michal J Wallace. The original moved only the orange bot
(blue stayed fixed). This Direct port is a **two-player** teaching enhancement: orange and
blue both move. No goal or scoring.

**Controls**
- **Orange:** WASD or Dvorak `,AOE` (and `<`)
- **Blue:** arrow keys
- **Esc:** pause / back to arcade

- **Direct:** playable. See [PORT.md](PORT.md) for faithful quirks and the deliberate 2P change.
- **Enhanced:** planned.
