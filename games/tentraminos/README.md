# tentraminos

Ludum Dare 27 (2013) match-4 puzzle with a 10-second clock.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** playable. Same rules (it runs the Direct logic unchanged) with a clearer board
  (rounded tiles, colour glyphs, linked groups, danger markers), a modern HUD (clock ring, best
  score, round stats), and juice on rotations, falls, landings and clears, plus synthesized SFX.
  See [PORT.md](PORT.md#enhanced-edition-enhanced-playable).

Controls (both editions): arrows / WASD / Dvorak `c h t n` move the 2×2 cursor; `z/x`, `k/l`, `o/u`
(or `j`) rotate; `p` pauses; Esc opens the arcade menu. Enhanced adds `m` (mute) and `g` (glyphs).
