# killem_all

From [gamemaker-stuff](https://github.com/tangentstorm/gamemaker-stuff) `killem-all.gmx/` (GameMaker: Studio 1.x).
A twin-stick shooter prototype. You thrust a drifting disc ship, aim its gun with the mouse and hose bullets. There are no enemies yet.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** planned.
