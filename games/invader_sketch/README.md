# invader_sketch

From [GameSketchLib](https://github.com/tangentstorm/GameSketchLib) course week 2 (Processing, 2011).
A Space Invaders clone by Michal J Wallace, made for the GameSketchLib video tutorial series.

Status: **Direct + Enhanced playable**.

- **Direct:** faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** visual/UI makeover over the same Direct `invader_logic.gd` (starfield
  stage, sprite glow, shoot/kill/shield juice, clearer HUD, title / over / win cards).
  No Alchementrix IP.

License: the course (including this game and `invaders.png`) is CC-BY 3.0 © Michal J. Wallace;
GameSketchLib itself is MIT. See `source/LICENSE.txt`.

Controls: ←/→ or A/D move · Space shoot (also starts / returns to menu) · Esc pause →
Back to Arcade. There is also an on-screen "Back to Arcade" button.
