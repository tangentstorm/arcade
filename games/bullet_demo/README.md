# bullet_demo

From [GameSketchLib](https://github.com/tangentstorm/GameSketchLib) course week 2 (Processing, ~2011): `BulletDemo.pde`.
A tech demo from the InvaderSketch tutorial series by Michal J Wallace. Not a full game.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** playable. Visual juice over Direct `game.tscn` in a SubViewport; see [PORT.md](PORT.md).
