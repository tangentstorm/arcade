# gamesketchlib_demo

From [GameSketchLib](https://github.com/tangentstorm/GameSketchLib) course week 2 (Processing, ~2011): `GameSketchLibDemo.pde`.
A tech demo from the InvaderSketch tutorial series by Michal J Wallace. Not a full game.

- **Direct:** playable. A faithful GDScript port; see [PORT.md](PORT.md).
- **Enhanced:** playable. Same Direct rules with glowing squares/bullets, trails, hit/soak/miss juice, an aim guide, and a side HUD. See [PORT.md](PORT.md).
